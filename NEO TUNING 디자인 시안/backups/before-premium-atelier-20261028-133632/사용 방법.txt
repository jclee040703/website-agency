NEO TUNING — 디자인 비교 4안
작성일: 2026-10-28

보는 방법
1. 'NEO TUNING — 4가지 시안.html'을 브라우저로 여세요.
2. 위쪽 A / B / C / D 버튼으로 디자인을 전환하세요.
3. '비교 바 숨기기'를 누르면 사이트 화면만 볼 수 있습니다.
4. 각 시안은 별도 HTML 파일로도 보관되어 있습니다.

A 스튜디오: 회백색 #F3F4F4 + 버건디 #8E2C27. 넓은 대표 사진, 선명한 Pretendard 제목, 서비스 3열.
B 아틀리에: 아이보리 #F1EEE8 + 브론즈 #725A38. 세리프 워드마크, 가는 Pretendard 제목, 사진과 글의 편집형 배치.
C 프리시전: 쿨그레이 #EDF1F3 + 블루 #35596D. 간결한 고딕, 사진/소개 분할, 선과 정렬을 강조한 구성.
D 갤러리: 화이트 #F7F7F5 + 딥그린 #38574A. 중앙 워드마크, 가벼운 제목, 서비스 사진의 높낮이를 달리한 배치.

사진, 글꼴, 스타일, 동작은 보관용 HTML 안에 포함했습니다.
인터넷 연결 없이 본문과 기능을 볼 수 있습니다. 외부 출처 링크를 열 때만 인터넷이 필요합니다.
상담 양식은 내용을 보여주는 체험 기능입니다. 입력 내용을 저장하거나 전송하지 않습니다.

파일 구성
dist/index.html, dist/style.css, dist/app.js: 실제 편집하는 원본 소스.
dist/assets: 기존 사진과 Pretendard 글꼴. 사진의 픽셀은 원본과 동일합니다.
dist/assets/fonts/OFL.txt: Pretendard 사용권. 보관용 HTML 안에도 포함했습니다.
before-concepts: 변경 전 HTML/CSS/JS 백업.
screenshots: PC 및 모바일 실제 브라우저 캡처.
export-local.mjs: 원본 소스를 보관용 HTML 5개로 변환하는 스크립트.
preview.mjs: 로컬 미리보기 서버. Node.js가 있는 환경에서 'node preview.mjs'로 실행합니다.

기존 프로젝트 C:\Users\c\OneDrive\neo-tuning 은 변경하지 않고 보존했습니다.
배포나 외부 업로드는 하지 않았습니다.

확인한 항목
웹페이지 뷰포트 PC 1440px, 모바일 390px에서 4안의 가로 넘침 없음.
Pretendard 실제 로딩, 사진 원본 비율, 밝은 배경의 글자/버튼/입력창 확인.
시안 전환, 비교 바 숨김/복원, 모바일 메뉴, 갤러리 이동, 전후 사진 확대/전환/닫기.
서비스 자동 선택, 상담 미리보기, 필수 선택 오류 안내, 키보드 포커스, 사진 출처 열기.
내보낸 HTML의 CSS/JS 일치, 사진 8개와 글꼴 및 라이선스 포함, 시안 전환과 확대 동작 확인.
개발자 콘솔 오류 없음.

검증 범위와 사진 한계
브라우저의 모바일 크기에서 확인했으며 실제 iPhone/Android 기기 및 Safari에서는 확인하지 않았습니다.
원본 전후 사진은 480×640px이며 촬영 각도가 달라 정밀한 겹침 슬라이더 대신 개별 비교와 확대를 사용합니다.

다음 자료가 있으면 더 발전시킬 수 있습니다: 가로형 주행 사진, 실제 랩핑 작업 장면과 표면 근접 사진,
