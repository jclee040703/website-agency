# 업체 정보 바꾸기

이 변경은 2026-10-28 GitHub main(17e1a61)을 기준으로 만들었습니다. 이후 PC에서 수정한 디자인에는 자동 적용하지 마세요. 먼저 별도 폴더에서 비교하세요. 다른 HTML 시안과 백업은 수정하지 않았습니다.

## 1. 수정할 파일

`dist/shop-config.js` 하나를 메모장이나 VS Code로 열어 주세요. UTF-8로 저장합니다.

- `name`: 매장명. 상단·하단 로고와 브라우저 제목에 함께 반영됩니다.
- `introduction`: 매장 소개. 실제 업체의 설명으로 교체하세요.
- `phone`: 전화번호. 입력하면 전화 걸기 링크가 생깁니다.
- `address`: 도로명주소와 상세주소.
- `hours`: 영업시간·휴무일.
- `visitNote`: 예약 방문, 주차 등 안내.
- `mapUrl`: 네이버·카카오 등의 지도 공유 주소.
- `channels`: 카카오톡, 예약 등 실제 상담 링크 목록.
- `services`: 서비스 목록. `title`은 이름, `caption`은 작은 영문 표기, `description`은 설명입니다. `image`와 `alt`는 사진 경로와 사진 설명입니다.

큰따옴표 안의 글자만 바꾸세요. 쉼표·대괄호·중괄호는 그대로 둡니다. 문장 안에서 줄을 바꾸려면 `\n`, 큰따옴표를 쓰려면 `\"`로 적으세요.

입력하지 않을 정보는 `""`로 두면 숨겨집니다. 서비스 설명·영문 표기·사진도 각각 비울 수 있습니다. 서비스를 모두 숨기려면 `services: []`, 상담 채널을 모두 숨기려면 `channels: []`로 바꾸세요. 매장 정보가 모두 비면 매장 안내 영역과 메뉴도 숨겨집니다. 상담에는 항상 ‘상담 후 결정’이 남습니다.

상담 링크는 아래 주석의 `//`를 지우고 실제 주소로 바꾸세요. 링크는 `https://`로 시작해야 합니다. 설정 파일에 비밀번호나 API 키는 입력하지 마세요. 이 파일은 방문자가 볼 수 있습니다.

## 2. 확인하기

`dist/index.html`을 브라우저로 열고 새로고침합니다. 전화·지도·상담 링크가 맞는지 확인하세요. 서비스 버튼을 누르면 해당 작업이 상담 양식에서 선택됩니다. 모바일에서는 메뉴를 열어 매장 안내로 이동해 보세요.

GitHub에서 바꾸려면 이 브랜치의 `dist/shop-config.js` → 연필(Edit) → 수정 → Commit changes 순서로 저장합니다. 실제 공개 사이트 반영에는 사용하는 호스팅 서비스로 변경 파일을 배포해야 합니다. 이번 변경은 main에 병합하거나 사이트를 배포하지 않았습니다.

## 3. 최신 로컬 디자인에 적용하기

최신 작업 폴더를 먼저 복사하세요. 새 파일 `shop-config.js`, `shop-template.js`를 dist에 추가하고, 이 브랜치의 index.html·style.css 변경 부분만 비교해 옮기세요. 최신 index.html·style.css를 통째로 교체하면 기존 로컬 디자인 수정이 사라질 수 있습니다. app.js는 변경하지 않았습니다.

## 실제 운영 전 확인

상담 양식은 기존처럼 미리보기 전용입니다. 저장·전송·접수 알림 기능은 없습니다. 고객은 별도로 표시된 실제 전화·상담 채널을 이용합니다. 업체 정보가 없을 때는 해당 채널도 표시되지 않습니다.

기존 갤러리·서비스 사진은 참고 자료입니다. 업체 실적으로 소개하지 말고 실제 업체 사진과 사용 허락이 확인된 자료로 교체하세요. 가상 실적과 후기는 추가하지 않았습니다.

## 검증 기록

- JavaScript 구문 검사 및 Node DOM 모형 테스트 통과: 기본/입력/빈 설정, 전화 링크, 부적절한 링크 차단, 텍스트 안전 처리, 서비스·상담 선택 동기화, 미선택 오류, 상담 미리보기.
